# Colony-Builder
Türkçe:  Tarayıcıda çalışan, NASA verilerine dayalı Mars kolonisi kurma ve hayatta kalma oyunu. Saf JavaScript ve WebGL, kurulum gerektirmez.  İngilizce (daha geniş bir kitleye ulaşır):  Browser-based Mars colony and survival game built on real NASA data. Pure JavaScript and WebGL, no install needed.
